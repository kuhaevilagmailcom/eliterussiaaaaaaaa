# MGN VPN

Telegram-бот для продажи и управления VPN-подписками.

## Готово

- одно постоянное UI-сообщение: все разделы редактируются внутри него без спама новыми меню;
- `/start` всегда восстанавливает/поднимает главное меню; если старое меню удалено пользователем, создаётся новое;
- защита от двойных нажатий и одновременных `/start`, чтобы не плодить дубликаты;
- обычные emoji в нижнем меню без дублирующих custom-иконок;
- одноразовый пробный доступ на 1 устройство после проверки подписки на Telegram-канал;
- тарифы: 15 дней — 49 ₽, 1 месяц — 99 ₽, 1 год — 2000 ₽, навсегда — 3333 ₽;
- платные подписки до 5 устройств;
- персональная ссылка подключения;
- список устройств и отключение отдельных устройств;
- реферальная ссылка вида `?start=ref_ID` и счётчик приглашённых;
- СБП через RollyPay: создание платежа, ссылка на оплату и ручная проверка статуса;
- SQLite WAL, защита от повторного зачисления оплаты;
- режимы `demo`, `3xui`, `webhook`;
- BotHost entrypoint: `main.py`.

## BotHost

Главный файл:

```
main.py
```

Основные переменные находятся в `.env`.

Для пробной подписки бот проверяет подписку на канал:

```env
TRIAL_CHANNEL_USERNAME=@mgnvpnn
TRIAL_CHANNEL_URL=https://t.me/mgnvpnn
```

Чтобы проверка подписки работала надёжно, добавьте бота администратором канала.

Для СБП нужны те же значения RollyPay, что используются в LIMYZINOV SHOP:

```env
ROLLYPAY_API_BASE=https://api.rollypay.io
ROLLYPAY_TERMINAL_ID=
ROLLYPAY_API_KEY=
ROLLYPAY_SIGNING_SECRET=
ROLLYPAY_TEST_MODE=false
```

Без `ROLLYPAY_API_KEY` кнопка СБП остаётся в интерфейсе, но создание платежа заблокировано.

## 3x-ui

Для реального VPN вместо demo:

```env
VPN_MODE=3xui
XUI_URL=https://panel.example.com
XUI_TOKEN=...
XUI_INBOUND_IDS=1
XUI_SUBSCRIPTION_TEMPLATE=https://vpn.example.com/sub/{sub_id}
XUI_VERIFY_SSL=true
```

В 3x-ui лимит трафика создаётся без ограничения. Пользователю в интерфейсе показывается только лимит устройств.

## Бонусная система

- за покупки VPN начисляются 💎 алмазы;
- за приглашённого пользователя: бонус после активации пробника и первой покупки;
- магазин за алмазы: 3/7/30 дней VPN и +1 устройство;
- промокоды добавляются администратором и выдаются из ограниченного склада;
- повторная проверка одного платежа или одного реферала не начисляет бонус повторно.

Админ-команды:

- `/diamonds TELEGRAM_ID AMOUNT`
- `/promoproduct SLUG PRICE TITLE`
- `/promocode SLUG CODE`


## Режим без серверов

Пока VPS/3x-ui не куплены, оставьте:

```env
VPN_MODE=demo
```

В demo-режиме бот не выдаёт фальшивую ссылку example.com. Подписки, пробный период, платежи, подарки, лимиты устройств, бонусы и рефералы сохраняются в БД. После подключения реального VPN-провайдера активные пользователи будут создаваться/синхронизироваться на сервере при следующем обращении к боту.

## Подключение реального VPN

Для одного 3x-ui сервера:

```env
VPN_MODE=3xui
XUI_URL=https://panel.example.com
XUI_TOKEN=...
XUI_INBOUND_IDS=1
XUI_SUBSCRIPTION_TEMPLATE=https://sub.example.com/{sub_id}
XUI_VERIFY_SSL=true
```

После переключения режима логика бота уже использует реальную персональную subscription-ссылку, срок действия, лимит устройств и список HWID устройств. Удаление устройства из бота отправляется в VPN-провайдер.

Точный API 3x-ui нужно один раз проверить на установленной версии панели после покупки сервера — разные сборки 3x-ui могут отличаться маршрутами API.
